# 부산 5색 웰니스 워크 — MVP 예약 플랫폼

부산 갈맷길을 활용한 두 가지 웰니스 프로그램(반려견 동반 · K-웰니스 관광)의 시범 운영 예약 시스템입니다. 하나의 코드베이스로 데스크톱은 브랜드 웹사이트, 모바일(768px 이하)은 하단 탭바 기반 앱 UI로 자동 전환되는 **반응형 PWA**입니다.

> 정부지원 창업 프로그램(모두의 창업 1기) 2라운드 심사 시연용 MVP 시뮬레이션 — 실결제·실서버 없이 완결된 시나리오로 동작합니다.

---

## 1. 완성된 기능

### 공통
- 반응형 레이아웃: 1024px 이상 데스크톱 GNB / 768px 이하 하단 탭바 앱 UI 자동 전환
- KO/EN 언어 토글 — 전체 페이지, 코스 소개, 예약 폼, 관리자 화면 라벨까지 전환 (기본 언어: 한국어)
- PWA `manifest.json` 적용 (standalone, 테마컬러 `#FBF8F3`, 앱 아이콘 512px), 모바일 첫 방문 시 "홈 화면에 추가" 안내 배너
- Pretendard 웹폰트, Font Awesome 아이콘, 파도+발자국을 결합한 커스텀 로고
- 코스맵은 외부 지도 API 없이 직접 제작한 일러스트풍 SVG로 구현

### 홈 (`index.html`)
- 히어로(헤드라인/서브 문구/CTA 2개), 이용 방법 3단계, 신뢰 지표 바
- 코스 A/B 카드, 시범 운영 참가 후기(코스별 3건, 문서 원문 그대로), FAQ 6개(아코디언), 안전 수칙 5개

### 코스 상세 (`course-a.html`, `course-b.html`)
- 코스 정보 표(대상/코스/운영/정원/가격/준비물), 프로그램 순서 타임라인 UI
- 직접 제작한 SVG 코스맵(출발지→경유지→도착지, 거리 라벨 포함)
- 코스B는 영문 콘텐츠 품질에 신경 써 별도 마케팅 톤으로 번역

### 예약 플로우 (`booking.html`) — 5단계 스텝 인디케이터
1. 코스 선택(A/B)
2. 날짜 선택 — 달력 UI, 오늘(2026-07-10) 이후 8주, 코스A는 토요일만 / 코스B는 화·목·금만 활성화, 날짜별 잔여석·마감 뱃지 실시간 표시
3. 인원 + 코스별 조건부 필드(반려견 정보 / 외국인 정보) 정확히 전환
4. 신청자 정보 + 개인정보 동의 + 현장결제 안내 문구
5. 완료 — 예약번호(`BW-YYMMDD-순번`) 자동 생성, 예약 요약 카드 표시

### 예약 조회 (`my-booking.html`)
- 예약번호 + 연락처 뒤 4자리로 조회, 예약 카드 표시, 취소 버튼(상태를 '취소'로 변경)

### 관리자 대시보드 (`admin.html`)
- 비밀번호 게이트(비밀번호: `wellness2026`, 세션 유지)
- 요약 카드 4개(총 예약/코스A/코스B/총 참가 인원, 반려견 수 별도 표기)
- 코스·날짜·상태 필터 + 최신순 테이블, 코스별 비중 도넛 차트(Chart.js)
- CSV 다운로드 버튼

## 3. 데이터 저장 방식 (★ 중요 — 기획서 대비 변경점)

원본 기획서는 `localStorage`(키 `bw_bookings`) 저장을 명시했으나, **"어느 기기에서 예약해도 관리자 대시보드에서 실시간 조회 가능"** 요구에 따라 **젠스파크 내장 RESTful Table API**(`tables/bookings`)를 사용하도록 구현했습니다.

- 테이블명: `bookings`
- 스키마 필드: `id, bookingNo, course(A/B), date, people, petName, petBreed, petSize, petVaccinated, petSociality, nationality, guideLanguage, hanbokSize, dietRestriction, name, phone, email, consent, status(확정/취소)`
- 예약 생성: `POST tables/bookings`
- 예약 취소: `PATCH tables/bookings/{id}` (`status: "취소"`)
- 조회: `GET tables/bookings` (전체 페이지네이션 자동 순회 후 클라이언트에서 필터)
- 정원 로직: 날짜별 `status≠취소` 예약의 `people` 합산 → 코스A 20 / 코스B 15 도달 시 달력에서 해당 날짜 '마감' 처리
- 예약번호 형식: `BW-YYMMDD-순번` (당일 생성 건수 기준 자동 증가)

> 참고: 미리보기(에디터)에서의 데이터와 퍼블리시 후 라이브 사이트의 데이터는 서로 다른 저장소를 사용합니다. Publish 이후에는 실제 방문자가 남긴 예약 데이터가 라이브 DB에 누적됩니다.

## 5. 아직 구현되지 않은 / 향후 개발 권장 사항

- **실결제 연동**: 현재는 "현장 결제 안내"만 표시. 실제 PG 연동 시 별도 백엔드 필요(본 프로젝트 범위 밖)
- **알림 발송**: 예약 확정/취소 시 SMS·이메일 자동 발송 (외부 인증 API 필요, 현재 미포함)
- **다국어 확장**: 일본어/중국어 가이드 안내는 기획서에 따라 "준비 중"으로 UI에 비활성 표시만 되어 있음. 실제 언어 확장 시 번역 리소스 추가 필요
- **관리자 계정 다중화**: 현재는 단일 공용 비밀번호 게이트(세션 스토리지 기반). 실운영 전환 시 서버 인증 체계로 교체 권장
- **이미지 자산 확장**: 현재 히어로/코스 이미지는 AI 생성 이미지 3종 사용. 실제 촬영 이미지로 교체 권장


- **차트**: Chart.js (코스별 비중 도넛 차트)
- **데이터 저장**: 젠스파크 RESTful Table API (`tables/bookings`)
- **PWA**: `manifest.json` + Apple touch icon (서비스워커 없이 A2HS 지원)

## 8. 배포 안내

로컬 미리보기가 아닌 실제 접속 가능한 URL로 배포하려면 **Publish 탭**에서 one-click 배포를 진행해 주세요. Publish 탭이 배포 프로세스와 실제 접속 URL 발급을 자동으로 처리합니다.

배포 후 관리자 페이지 접근 방법:
- 주소: `(배포된 도메인)/admin.html`
- 비밀번호: `wellness2026`

## 9. 🔒 제한 공개(비공개 미리보기) 모드

아직 전체 공개하기엔 이르다는 판단에 따라, 현재 사이트는 **"접속 코드를 아는 사람만 볼 수 있는" 제한 공개 모드**로 설정되어 있습니다.

### 동작 방식
- 일반 방문자가 `index.html` 등 아무 페이지로 들어와도 자동으로 `coming-soon.html`(준비 중 안내 페이지)로 이동합니다.
- 안내 페이지에서 **접속 코드**를 입력하면 인증되어 사이트를 볼 수 있고, 이후에는 같은 브라우저에서 재방문 시 다시 코드를 입력하지 않아도 됩니다(브라우저에 인증 정보 저장).
- 또는 **특수 링크**(`?key=코드`가 붙은 URL)로 접속하면 코드 입력 없이 바로 인증되어 자동 입장됩니다. 이 링크를 심사위원이나 관계자에게 공유하면 편리합니다.
- `admin.html`은 로직상 별도의 자체 비밀번호 게이트(`wellness2026`)가 있어 이번 제한 공개 설정과는 무관하게 항상 보호됩니다.
- 모든 공개 페이지에 `<meta name="robots" content="noindex, nofollow">`를 적용해 구글 등 검색엔진에 노출되지 않도록 처리했습니다.

### 현재 설정값
- 접속 코드: `bw-preview-2026`
- 공유용 특수 링크 예시: `(배포된 도메인)/index.html?key=bw-preview-2026`
- 설정 파일: `js/site-gate.js` (상단 `ACCESS_CODE`, `SITE_LOCKED` 값) / `coming-soon.html` (동일 코드 값 유지 필요)

### ⚠️ 유의사항 (정적 사이트의 구조적 한계)
이 방식은 "링크를 모르는 일반인의 우연한 방문을 막는" 용도의 **소프트 게이트**입니다. 정적 사이트는 서버가 없기 때문에, 브라우저 개발자도구로 소스 코드를 열어보면 접속 코드 문자열 자체가 노출될 수 있습니다. 즉, **비밀번호를 절대 알아낼 수 없는 완전한 보안 잠금은 정적 사이트 구조상 제공이 어렵습니다.** 사내 관계자·심사위원 등 제한된 대상과 링크를 공유하는 시범 운영 단계용으로는 충분하지만, 민감한 개인정보나 결제 정보를 다루게 될 경우엔 서버 기반 인증 도입을 권장합니다.

### 전체 공개로 전환하는 방법
나중에 사이트를 정식으로 공개하고 싶을 때는 다음 중 하나를 요청해 주세요:
1. "제한 공개 모드를 해제해줘" → `js/site-gate.js`의 `SITE_LOCKED`를 `false`로 변경하고 각 페이지의 `noindex` 태그도 제거해 드립니다.
2. 접속 코드만 새로 바꾸고 싶다면 "접속 코드를 OOO로 바꿔줘"라고 요청해 주세요.
